# 权限与安全边界

本应用是用户在场的单任务辅助工具，不是远程控制服务。无需账号、无中转服务器、无遥测。默认不开无障碍，写作、模型和搜索不依赖无障碍或悬浮窗权限。

## 数据流

| 数据 | 去向 |
|---|---|
| 用户输入、所选技能说明、用户提示词 | 所选模型端点。在生成手机计划时，还会包含目标应用名和包名。 |
| 搜索词、搜索服务密钥 | 提交给所选搜索 API。使用检索技能时，其返回的摘要和链接会随任务一起提供给所选模型。 |
| 免费 Bing | 将编码后的关键词交给系统浏览器打开微软 Bing。Pilot 没有浏览器 Cookie、历史或结果读取接口。 |
| 目标窗口的可见可操作标签 | 只在授权任务中在设备上匹配，不发送截图、控件树、页面文字或剪贴板至模型。 |
| 配置和记录 | API 密钥用 Android Keystore 的 AES-GCM 密钥保护；应用不启用 Android 数据备份。最多保留 30 条本地活动摘要，可清除。请求正文不写入历史。 |

用户必须信任自填端点和第三方服务商；不要把 API Key 写入提示词、URL、技能文件或 issue。Keystore 不保证每台手机都有独立安全芯片，无法保护已经失陷的系统。请求可能产生第三方费用；点停止不能撤回已发送的网络请求。

## 控制规则

- 仅用户发起、选择一个已安装且允许的目标后才可执行。模型或导入的技能不能指定其他包、运行脚本、执行 shell 或点击任意坐标。只能打开目标、匹配标签点击、翻页、向普通输入框填草稿。
- 本地验证结构化计划、展示预览，再由设备上的控件确认。窗口、目标和敏感字段检查是额外防护，不是理解任意第三方应用的保证。**执行前以真实屏幕和确认内容为准**。不支持付款、发消息、删除、授权、登录或密码输入。
- Android 13 及以上或厂商系统可能限制侧载应用使用无障碍服务。请遵循设备的系统提示；如无法开启，可继续使用非控制功能。不要为启用本应用而关闭设备防护。
- 导入文件只是 JSON 提示词，不含可执行代码。模型可能受不可信提示影响，请核对来源、操作计划与资料出处。
- 系统权限可在设置中撤销；清除应用存储或卸载会移除配置、技能和密钥。正式签名与体验签名不同，更换安装前先备好原始 API Key。

## 报告问题

向维护者私下报告安全问题；若仓库开启 GitHub 私密漏洞报告，请优先使用。提交最少必要的机型、系统版本及脱敏复现步骤，不要附带真实令牌、私人消息、支付信息或屏幕转储。
