## v1.2 视觉改动验证

- **亮色主题**：冷白雾面背景 `rgb(238,243,241)`、白色磨砂卡片、深墨色文字 `rgb(21,38,34)`、青绿强调色。文字对比度经计算：正文 14:1、次要文字 5.3:1、主按钮白字最低 4.7:1，符合 WCAG。
- **清透玻璃反射（v1.4 最终）**：按真实玻璃的菲涅尔特性重做——正对的中心反射率约 4%（几乎全透），只有圆角斜面与光源方向出现清晰镜面高光，边缘保留 RGB 色散。已去除会把中心蒙白的 body 基础着色/环境底光，以及把高光扭成波纹的 SVG 湍流位移滤镜。软件路径分区实测：**中心平均 alpha 1/255、整体平均 8，纯白过曝像素为 0**，身后文字可透过导航清晰阅读；WebGL 路径为 GLSL ES 1.00。（本机 Chromium 无 WebGL，实测软件路径。）
- **通透度根因与量化（v1.4 最终修正）**：canvas alpha 很低≠看起来通透，真正的糊来自 CSS 叠层。在玻璃正后方注入高对比棋盘逐层测量：关闭 `backdrop-filter` 时条纹列对比度从 67.3/峰峰 188.7 恢复到 67.9/245.6、关闭选中滑块时降到 25.3/89.2——确认 `blur(7px)` 糊背景与 94% 白选中药丸是两个主因（裸基准 71.5/255）。移除背景模糊、仅保留 `saturate(106%)`，并把白底/滑块降到近乎透明后，与裸棋盘的相关性（背景保真度）从 **0.173 → 0.931**；玻璃本体改由增强的 canvas 边缘菲涅尔高光（`edge` 增益 0.9→2.2）与内阴影描边呈现，中心仍全透。真实浅色页面上玻璃轮廓清晰、选中态可辨。
- **可见折射（v1.4 最终重做）**：仅靠 `backdrop-filter:url()` 位移背景在浅灰纯色页面上肉眼不可见（纯色位移仍是纯色），且 Android WebView 对 `backdrop-filter:url()` 支持不一。改为在 canvas 光学层直接绘制折射特征，任何背景下可见：圆角**青/品红色散边**、边缘**亮唇 + 内侧暗线**（弯折/全反射）、底缘**焦散亮弧**，中心保持通透。色散以独立加色层 + 自身 alpha 输出（避免被 4% 菲涅尔压制）。软件路径分区实测：侧边因色散 b 通道高于 r/g（29–35 vs 25–29）、侧边平均 alpha 46、顶部 33、底部焦散 31、中心 alpha 1/255、**纯白过曝 0**，Chromium 144 截图确认左右圆角青/品红彩边清晰自然、文字锐利、0 JS 错误；WebGL 路径 GLSL ES 1.00 同步实现（本机无 WebGL，实测软件路径）。`backdrop-filter:url(#glass-refract)` 的 6KB 内联 SDF 位移图作为加分项保留（支持时叠加真实背景弯折，不支持时静默退化）。`prefers-reduced-motion`/减少动态效果时关闭位移层。无网络、无外部资源。
- **可拖动玻璃滑块：力度变形 + Q弹 + bug 修复（v1.4 最终）**：CDP 实测按住滑块拖动——小幅拖放大 `scaleX 1.147/sy 1.025`、大幅拖放大 `1.433`（并沿拖动方向拉长、纵向压到 1.005），形变随力度非线性变化；松手吸附到最近标签（`aria-current deck → links`）、点击切换回归正常。双欠阻尼弹簧（ζ≈0.3）：松手 sx 采样 `1.33 → 1.03 → 0.87 → 1.05 → 1.0`，冲过静止点后多次振荡归位，明显 Q 弹。边界钳制：超量拖动时 `tx` 停在预留放大余量内，滑块圆角始终在导航栏内不被 `overflow:hidden` 裁平。**bug 修复**：命中判定由“未放大宽度”改为滑块实时 `getBoundingClientRect()`（含 transform），实测放大状态下抓滑块最右边缘识别为 `knob=true, capsule=false`（不再误触发胶囊形变），0 JS 错误。滑块为叠在导航玻璃之上的第二层独立玻璃。
- **四向拖拽弹性（v1.3 起，v1.4 保留）**：
  - 横向左右：`scaleX 1.055 / scaleY 0.965`，位移 ±3.4px；
  - 纵向上下：`scaleY 1.088 / scaleX 0.982`，位移 ±2.06px；
  - 斜向：两轴同时形变；幅度为二次非线性（小幅拖拽几乎无形变）；
  - 回弹：五个方向均检测到越过静止点的过冲（欠阻尼弹簧），末值归 1.000；拖拽不误触发标签切换，无 JS 错误。幅度已从上一版 18% 收敛到 5–9%。
  - v1.4 新增：拖拽时内部反射沿拉伸反方向以一阶阻尼滞后流动，随形变归位；CDP 实测斜向拖拽中途 `scale(1.0169,0.9984) skew(-0.47deg)`、松手归 `scale(1,1)`，全程 0 异常。
- **一键复制（v1.4）**：本次反馈面板新增「复制」按钮；注入结果后按钮可见，调用 `document.execCommand('copy')` 并在失败时提示长按手动复制。
- **Chromium 同尺寸（540×960）渲染**：标题、任务区、技能库、连接页全部文字与控件完整，无横向溢出；导航胶囊整块玻璃质感、身后文字可透出、标签清晰，无过曝或毛刺。
