# pilot one thing

**一次，只做一件事。** 一个面向 Android 10+ 的中文手机助手。写下任务、挑选技能，或把一个可检查的操作计划交给自己选定的应用。无需 Pilot 账号，无中转服务器。

| 能力 | 实现 |
|---|---|
| 指挥台 | 本机任务状态、结果、最近活动、可中止的模型请求；不把任务正文写入历史。 |
| 监督操作 | Android AccessibilityService；每次仅一个目标、最多 8 步。打开应用、点击支持的可见导航标签或计算器键、滚动、在已聚焦的普通文本框输入草稿。先审阅计划，再在浮层上确认。 |
| 模型 | DeepSeek、通义千问、硅基流动、OpenAI、Gemini 兼容接口、OpenRouter，另有自定义 OpenAI 兼容端点。预设会填入接口和模型；填写自己的密钥即可。模型名或账号权限变化时可手动修改。 |
| 参数 | 模型 ID、temperature、top_p、max_tokens、系统提示词。第三方模型是否采纳每个采样参数取决于服务商。 |
| 搜索 | 免费 Bing 浏览器入口；Tavily、Brave、Serper、博查、Exa；自定义 HTTPS GET/POST、鉴权头、查询字段、结果提取路径。检索技能可将 API 结果用于带来源的整理。 |
| 技能 | 14 个内置技能，覆盖手机导航、计算、翻页、草稿、写作、规划和检索。支持本机 JSON 文件导入，预览提示词后生效。 |
| 视觉 | 原创折射玻璃主体、环境反射高光、多视角弹簧动画、减少动态效果选项。执行手机操作时，显示四边窄幅彩色波纹和停止控制条；不依赖苹果组件。 |

## 导航：整块通透玻璃与开屏

底栏是悬浮在内容上方的清透玻璃，而不是实色工具栏。按真实玻璃的菲涅尔特性，正对的中心几乎全透、身后内容清晰可见，只有圆角斜面与光源方向出现清晰的镜面高光与轻微 RGB 色散彩边。`backdrop-filter` 内联位移贴图对玻璃背后的真实页面做透镜折射：中心笔直、圆角处把背景向外弯折。选中项是叠在导航玻璃之上的第二层玻璃滑块，可以直接按住拖动（钳制在导航栏内、松手吸附到最近标签），放大与拉伸随拖拽力度非线性变化（拖得越用力越大、越扁长），松手以欠阻尼弹簧 Q 弹回弹；按住胶囊空白处则可向上下左右任意方向拖拽，玻璃沿拖拽轴非线性拉伸、内部反射随形变流动，松手带过冲回弹，轻触仍正常切换页面。本次反馈可一键复制。开屏可轻触跳过，不等待网络。更多说明见 [更新记录](CHANGELOG.md)。

## 第一次使用

1. 从本次交付或可信的项目 Release 获取 APK 并安装。**不需要开通任何权限就可以先体验界面和使用 Bing。** 选择「快捷起飞 → Bing 搜索」，输入主题；结果在系统浏览器里打开，需要联网，但不需要 API Key。
2. 进入「连接 → 模型服务」，选预设、输入密钥、保存，点「测试连接」。预设地址为**完整请求 URL**，不是只填域名。搜索 API 在「搜索服务」单独配置和测试。凭据只返回“已配置”状态，不回显。
3. 想控制手机时，在「设备」选择普通目标应用，例如计算器或时钟，按说明由本人在系统设置里授予无障碍与悬浮窗权限。可以先用无密钥的「打开应用」演示验证权限。**系统权限不可由应用自行开启。**
4. 选择「桌面计算器」，输入 `在所选计算器输入 2+3 并查看结果`。核对模型生成的动作，确认计划；在悬浮条逐步点「下一步」。标签不存在、窗口变化、超时或敏感页面时任务会停止。型号不同，控件可能使用不同的可访问标签。不支持的步骤请手动完成。
5. 「技能库 → 导入技能」选择 [示例文件](examples/reading.skill.json) 可添加一个「阅读卡片」技能。按同一自定义 ID 重导会更新；不能替换内置技能。

**它不是看屏幕自己点一切的代理。** 模型只拿到你输入的任务、技能和目标应用标识，不拿截图或页面树。普通写作不需要设备权限。Bing 浏览器模式不抓取网页；想让模型自动使用检索内容，请选择并配置搜索 API。无需密钥的本地打开演示不是离线大模型。

## 开发、测试和发布

```sh
# JDK 17；Android SDK Platform 34 + Build Tools 34.0.0
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest
./gradlew :app:lintDebug :app:assembleRelease
```

- 构建输出：`app/build/outputs/apk/debug/app-debug.apk`，默认可安装；普通 release 任务产出未签名 APK。另见 [构建说明](docs/BUILD.md)、[签名与 GitHub](docs/RELEASE.md) 和 [交付验证记录](docs/VALIDATION.md)。
- 结构：`app/src/main/java/io/pilot/onething/` 为安卓宿主、网络、权限、计划和执行器；`app/src/main/assets/ui/` 为离线界面；`skills.json` 为技能目录；`examples/` 为技能包；`.github/workflows/` 为自动构建。
- GitHub：解压后以 **README、gradlew 和 .github 所在层**为仓库根目录。二进制放 Releases，不含私钥、不提交 API Key。不要将测试 fixture 当作正式 APK。
