# pilot one thing · 本机 WebView 界面

## 运行

Android 主机加载 `ui/index.html`。HTML、CSS、JavaScript、矢量图标与两份 WebP 均为本地文件；没有 CDN、构建步骤、前端框架、在线字体或分析服务。所有原生操作通过 `window.Pilot.invoke(JSON.stringify({op,...}))` 发起。浏览器可直接预览布局，但没有桥接时不会生成设备状态、技能或事件记录。Bing 免密钥，不是离线搜索引擎：可以离线打开本地输入界面，获取网页结果仍需联网。

## 使用路径

- **指挥台**：输入任务，选择技能，执行。主机报告 `busy` 或 `active` 时按钮变为停止。本地「打开应用」演示只请求 `demo`，后续目标选择、计划核对、权限说明由主机负责。「Bing 搜索」在明确提交关键词后才交给系统浏览器。最近事件来自主机；清除需再次确认。
- **技能库**：按分类或关键词查找。点技能可审阅描述与提示词，再点「使用此技能」回到指挥台；既有任务文字保留。导入由原生文档选择器处理。
- **连接**：分别编辑模型和搜索配置。服务预设全部来自主机。支持 Endpoint、模型 ID、密钥、Temperature、Top P、Max Tokens、System Prompt，以及自定义搜索的 GET/POST、查询字段、鉴权头与前缀、结果路径及字段映射。只有点击「保存配置」才发送当前面板的差异补丁。测试使用已保存设置；发送测试前提示可能计费。
- **设备**：顶栏「设备」入口可查看目标应用、无障碍和悬浮窗的主机报告状态，并可跳到原生选择或授权流程。「减少动态效果」首次遵循系统偏好；手动修改后只将这一个布尔值写入本地存储。

## 桥接与状态约束

- 入站：`window.onPilotState(state)`、`window.onPilotEvent({type,message})`。出站：`state`、`save({data})`、`run({task,skill})`、`bing({query})`、`search({query})`、`test`、`demo`、`import`、`target`、`permissions({kind})`、`stop`、`clearHistory`。`window.pilotBack()` 为原生返回键报告是否已处理。
- 密钥字段不会回显已保存值。未保存的编辑只存于页面内存，并按服务类型、提供方 ID 隔离；保存成功后释放已提交的对应草稿，失败时保留输入以便修正。切换服务方不会把上一家的端点或密钥写入新配置。任务、查询、密钥或结果均不写入 Web 存储。模型输出、技能和历史一律作为纯文本插入。
- 移动端使用中文标签、系统字体、焦点样式、弹层焦点循环和返回键；浏览器没有原生主机时显示未连接说明。常见 WebView 旧版缺失的尺寸和内边距特性有 CSS 回退。

## 光学视觉

`optic.webp` 是两层圆角三角形玻璃环的离线程序化光线追踪图。渲染采用有符号距离场求交、曲面法线、折射率 1.49、Fresnel 反射、全内反射、路径吸收和有限距离棚灯。`optic-motion.webp` 包含同一几何体的 15 个视角；`optic.js` 在低分辨率 Canvas 上插值，指针驱动阻尼弹簧。离开首屏、切换页面、应用进入后台或开启减少动态效果都会停掉动画循环。静态海报不依赖 Canvas 或 WebGL。

## 验证范围

Chromium DOM/桥接契约测试（无网络、使用测试夹具）覆盖：输入任务与技能选择、保存和失败重试、提供方隔离、密钥替换/清除、原生状态更新期间保留草稿、自定义搜索字段、Bing/演示、目标与授权请求、停止按钮、减少动态效果以及结果文本渲染。320、360、390、600、900 CSS px 宽度下，四个页面共 20 次水平溢出检查通过。浏览器测试不代表网络请求、系统权限或 Android 自动操作已经成功；这些交由宿主设备测试验收。
