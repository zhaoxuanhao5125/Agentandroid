# Building Pilot

The app is a Java Android application, package `io.pilot.onething`, min SDK 29 (Android 10), target/compile SDK 34 (Android 14). The `smoke/` sources test the toolchain only and are **not** included in a normal APK.

## Standard build: Android Studio / Gradle / CI

Use JDK 17, Gradle Wrapper 8.7 (checked in), and Android Gradle Plugin 8.5.2. Install Android SDK Platform 34 and Build Tools 34.0.0 through Android Studio's SDK Manager or the official command-line tools. Platform Tools are needed only to use `adb`.

```sh
sdkmanager 'platforms;android-34' 'build-tools;34.0.0' 'platform-tools'
# Point ANDROID_HOME to that SDK, or set sdk.dir in a local, untracked local.properties.
./gradlew :app:assembleDebug
# Output: app/build/outputs/apk/debug/app-debug.apk
```

On Windows use `gradlew.bat :app:assembleDebug`. The first Gradle build needs access to Google Maven, Maven Central, and the Gradle distribution. A primed cache can be reused with `--offline`. If a machine's global Gradle init scripts override the repositories, use a clean `GRADLE_USER_HOME`. On the build host for this project the following are already primed:

```sh
export ANDROID_HOME="$HOME/.cache/pilot-android/sdk"
export GRADLE_USER_HOME="$HOME/.cache/pilot-android/gradle"
./gradlew --offline :app:assembleDebug
```

For an independent toolchain check without app sources, run `./gradlew -PsmokeOnly :app:assembleDebug`; its output is `smoke/build/gradle/outputs/apk/debug/app-debug.apk`. **Do not distribute that fixture as the app.** It shares the application ID; use a test device or profile, not one with the real app installed.

## Standalone fallback: framework-only debug APK

For Linux x86_64 hosts without a populated Gradle cache, the checked-in CI-independent fallback uses the official `aapt2`, `javac`, D8, `zipalign` and `apksigner`. Requires Bash ≥4, a JDK (17 recommended), Python 3, and installed `platforms;android-34` + `build-tools;34.0.0`. It does not support third-party dependencies, manifest merging, Kotlin, AIDL, native libraries, or release signing; use Gradle if these are added.

```sh
# Optional, if these SDK packages aren't installed. Review the Android SDK
# license at https://developer.android.com/studio/terms before using the SDK.
# Fetches SHA-256-pinned Google SDK archives. Requires curl, sha256sum and unzip.
./tools/bootstrap-sdk-linux.sh
# Defaults to ~/.cache/pilot-android/sdk; ANDROID_HOME takes precedence.
./tools/build-debug.sh --smoke  # smoke/build/standalone/smoke-debug.apk
./tools/build-debug.sh          # app/build/outputs/apk/standalone/app-debug.apk
```

With the SDK present, the standalone build makes no network requests. A development keystore is created locally in `~/.android` (or `ANDROID_USER_HOME`); the project does not contain one. All APKs above are debug builds: use a separate protected release signing process for publication. Debug APKs from different keystores cannot update each other in place.

## Inspect or run the built APK

```sh
apk=app/build/outputs/apk/debug/app-debug.apk
bt="$ANDROID_HOME/build-tools/34.0.0"
"$bt/apksigner" verify --verbose "$apk"
"$bt/zipalign" -c 4 "$apk"
"$bt/aapt" dump badging "$apk"
"$ANDROID_HOME/platform-tools/adb" devices -l
# On a connected API 29+ device with USB debugging enabled:
"$ANDROID_HOME/platform-tools/adb" install -r "$apk"
```

The wrapper JAR was generated by the official Gradle 8.7 binary and matched its [published SHA-256](https://services.gradle.org/distributions/gradle-8.7-wrapper.jar.sha256): `cb0da6751c2b753a16ac168bb354870ebb1e162e9083f116729cec9c781156b8`. The binary distribution checksum is pinned in `gradle/wrapper/gradle-wrapper.properties`.
