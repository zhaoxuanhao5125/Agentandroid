# 项目介绍与主要功能

## 项目简介

**pilot one thing** 是一个面向 Android 10 及以上设备的中文手机助手。用户可以描述任务、选择技能，并在需要时审阅一个有限范围的手机操作计划。

项目源码以版本快照形式归档于仓库根目录的 `v1.4/` 至 `v3.7/`。最新版本的实现和使用细节请以 [`v3.7/README.md`](../../v3.7/README.md) 为准。

## 主要能力

### 任务与技能

应用提供本机任务状态、结果和最近活动视图，并支持内置技能及从本地 JSON 文件导入自定义技能。技能可以用于导航、计算、写作、规划和检索等任务。

### 模型服务

可配置兼容 OpenAI API 格式的模型端点，并提供常用服务商预设。使用模型服务通常需要用户自行提供对应服务商的 API 凭据；服务商的可用性、计费和条款由服务商决定。

### 搜索

支持内置 Bing 浏览器入口，以及多种搜索服务和自定义 HTTPS 搜索端点。具体可配置项和接口约定见 [`v3.7/SERVICES.md`](../../v3.7/SERVICES.md)。

### 受控的设备操作

设备操作依赖 Android AccessibilityService。应用面向明确选择的目标应用生成有限步骤的计划，并由用户审阅、逐步执行；需要的权限应由用户在系统设置中主动授予。

### 界面与交互

应用包含玻璃质感视觉效果、任务执行状态展示及停止控制。具体功能可能随归档版本变化，请查看对应版本目录中的 README 和更新日志。

## 设计边界

- 模型根据用户任务、技能和目标应用标识生成计划。
- 项目说明指出，模型不会收到屏幕截图或页面树。
- 设备操作需要系统权限，且应由用户审阅计划并控制执行。
- 普通写作或不涉及设备操作的功能无需启用设备控制权限。
