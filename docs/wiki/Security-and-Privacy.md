# 权限、安全与隐私

本项目涉及模型服务、搜索服务和可选的 Android 辅助操作。使用前请阅读最新版本的 [`SECURITY.md`](../../v3.7/SECURITY.md) 与应用内权限说明。

## 设备权限

- 浏览界面或使用不涉及设备控制的功能时，不需要启用无障碍服务。
- 如需辅助操作目标应用，用户需要在系统设置中主动启用 AccessibilityService，并按应用提示授予所需权限（例如悬浮窗权限）。
- 只选择自己有权操作的应用，并在执行前审阅计划；对发送、删除、支付等重要操作尤其谨慎。
- 可在执行过程中使用应用提供的停止控制。

## 模型与搜索服务

- 使用第三方模型或搜索 API 时，请自行查看服务商的隐私政策、计费规则、地区限制和使用条款。
- 请不要在任务内容中输入不必要的敏感信息。
- API 密钥应妥善保管，不要写入提交到仓库的源代码、示例配置或日志。
- 仅使用可信的 HTTPS 服务端点。

## 项目数据边界

项目 README 描述的操作流程中，模型依据用户提供的任务、技能和目标应用标识生成计划，不接收屏幕截图或页面树。具体数据处理行为可能依版本和配置不同，请以正在使用版本的安全与隐私文档及代码实现为准。

## 负责任地使用

本项目提供的是辅助工具，不保证模型输出始终正确。用户应理解并确认每一步操作的目标与后果，不应将未经审阅的模型计划用于高风险场景。

## 安全问题报告

发现安全问题时，请先阅读 [`v3.7/SECURITY.md`](../../v3.7/SECURITY.md) 中的报告指引，不要在公开 Issue 中披露可被利用的敏感细节。
