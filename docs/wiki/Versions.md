# 源码版本与归档说明

## 版本列表

仓库归档了 19 个版本的独立源码快照：

- v1.x：v1.4、v1.5、v1.6、v1.7、v1.8、v1.9
- v2.x：v2.0、v2.1、v2.2、v2.3、v2.4
- v3.x：v3.0、v3.1、v3.2、v3.3、v3.4、v3.5、v3.6、v3.7

完整索引和各版本文件数量、源码大小见[主 README](../../README.md#源码版本索引)。

## 应该从哪个版本开始？

建议从最新归档版本 [`v3.7/`](../../v3.7/) 开始构建和开发。历史版本用于查阅和对比，不要把不同快照的源码混合构建。

## 目录结构

每个版本目录通常包含 Android Gradle 项目文件，例如 `app/`、`gradle/`、Gradle Wrapper、文档、测试及示例。各版本目录中的 README 提供该版本适用的能力、环境要求和命令；目录内容会因版本而异。

## 归档快照说明

各目录是独立的完整源码快照，可以作为相应版本的 Android/Gradle 项目打开。版本号表示归档源码版本，不应据此推断仓库中一定存在对应的 GitHub Release 或可下载 APK。
